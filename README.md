# StockDashboard

A personalized stock tracking dashboard built with Python, Streamlit, and yfinance.

## Features

- Dark mode black/blue/grey UI
- Sidebar stock profiles
- Add tickers dynamically
- Price chart visualization
- 20 / 50 / 200 day moving averages
- Multiple timeframe support

## Tech Stack

- Python
- Streamlit
- yfinance
- Plotly
- Pandas

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
